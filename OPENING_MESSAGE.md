# Opening message

Copy this at the start of a session:

```text
Read this repository: [repository URL]
Start with NOTES.md, then inspect the relevant project files and recent history.
Tell me what the record supports about the current state,
what remains uncertain, and what the next task should be.
Confirm before starting work.
```

If the tool cannot access the repository, upload or paste the current `NOTES.md` map and the relevant files for the task:

```text
Here is the current NOTES.md map for my project:

[paste or attach the handoff]

Here are the relevant project materials:

[attach or paste the files, outputs, or history the task requires]

Use the handoff to orient yourself, inspect the supplied evidence, tell me
what the record supports and what remains uncertain, and confirm before
starting work.
```

Do not let the AI start substantial work until you have checked its summary and confirmed the task. During the session, ask for a checkpoint after a decision, failed approach, material change, priority change, or before switching tools. Use `AI_WORKFLOW.md` for the full protocol.
