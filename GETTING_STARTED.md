# Project Memory Starter Kit — Getting Started

You are not supposed to run this by hand. Set it up once, paste one block per session, and the AI keeps the note updated for you.

1. Create one **private** repository for your project.
2. Copy `NOTES.md` into it and fill in exactly **three sections by hand**: Goal, Current state, Repository map.
3. Open `START_HERE.md` and copy the block. Each session, paste that block together with your `NOTES.md` (or the repository link).
4. The AI opens (reports state + next task), checkpoints on its own when something material happens, and drafts the closing update before the session ends.
5. You say "yes" / "no" / "commit" and fix anything the AI got wrong.
6. Read `SECURITY_CHECKLIST.md` before every commit.

The repository is your project record. `NOTES.md` is the map and handoff inside it. The AI drafts; you verify and own the committed record.
