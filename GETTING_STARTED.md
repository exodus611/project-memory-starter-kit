# Project Memory Starter Kit — Getting Started

The quick path (from the book *The Project Has a Memory*):

1. Download this kit (all files below, or the ZIP bundle).
2. Create one **private** repository for your project.
3. Copy `NOTES.md` into it and fill in **Goal**, **Current state**, and **Repository map**.
4. Start every AI session with `OPENING_MESSAGE.md`.
5. During work use `WORKING_MESSAGE.md`; at material events use `CHECKPOINT_MESSAGE.md`.
6. Before ending a session, run `CLOSING_ROUTINE.md`.
7. Read `SECURITY_CHECKLIST.md` before every commit.

The repository is your project record. `NOTES.md` is the map and handoff inside it.
