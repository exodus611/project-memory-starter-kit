Project Memory Starter Kit

One file. One block. Fill in three lines once — then paste one message per AI session, and the AI runs the rest.

↓ Download — 1 file Read START_HERE online Get the book on Amazon

The ZIP contains exactly one file: START_HERE.md. The block and the NOTES.md template are both inside it — nothing else needed.

1

Set up once

Create a private repo, copy the NOTES.md template in, and fill three fields by hand: Goal, Current state, Repository map.

2

Paste one block per session

Take the single block from START_HERE and paste it together with your NOTES.md (or the repo link).

3

The AI runs the rest

Opens by reporting state and next task, checkpoints in the middle, writes the closing update at the end. You just say yes / no / commit.

Is it one block or eight?

One block. The older kit had several per-stage files — they now sit in reference/ for the curious. You never need them.

Do I maintain the note myself?

No. After setup, the AI drafts every update; you review and approve.
