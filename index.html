Public quick start

Let the project remember itself

One block for your AI coding agent. It installs or repairs project memory when needed; otherwise it reads the evidence and asks what to do next.

Open the one block How it works ↓ Download 267-word card Complete Reader Kit

Open the one block is the automatic public Basic Block. The ZIP contains only the 267-word manual card. The complete Master Block is inside the book.

1

Paste once

Open your project in an AI coding agent and paste the single setup block. In the same message, add your project idea or today's task directly below it in ordinary words. For an established repository this is optional. You do not copy workflows or choose paths by hand.

2

The agent chooses the path

It detects whether the project needs setup, repair, or an ordinary session. Only unresolved questions are grouped into one short message.

3

Install once, then work

New projects get one approval for setup and one for commit/push. Ready projects skip installation, report their state, and ask whether to start the proposed next task.

The Basic Block does not install these checks. In the complete setup they run in the user's own repository and GitHub Actions environment; they do not upload project files to the author.

Can I keep using the free Basic Block?

Yes. It is enough to create project memory and maintain a simple start-to-close loop for an ordinary project. It intentionally omits automated freshness and release checks, mid-session checkpoints, and the full security protocol.

What does the complete Reader Kit add?

It is designed for longer and higher-stakes work: mid-session checkpoints, context-compaction protection, multi-agent handoff, evidence discipline, connected-agent permissions, recovery after failures, and the complete closing and security protocol.

Why keep memory with the project?

The AI tool can change. A human-readable, versioned project record remains inspectable, portable, and under your control.

Will the same block work outside a full coding agent?

It adapts, but permissions matter. A coding agent with repository and terminal access can install and test everything. A read-only GitHub chat can prepare exact files but cannot apply them; a plain chat without project files can only guide setup. The block identifies the mode instead of pretending it completed work.
