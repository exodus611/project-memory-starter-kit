Setup in 5 steps

  • One project, one private repository. Keep code, documents, outputs, workflows, and history there.
  • Copy NOTES.md in and fill in Goal, Current state, and Repository map before the first commit.
  • Start every session with OPENING_MESSAGE.md.
  • Work, then checkpoint after decisions and failures; close with CLOSING_ROUTINE.md.
  • Review before committing — read SECURITY_CHECKLIST.md first.

The repository is your project record. NOTES.md is the map and handoff inside it — the AI session is a temporary worker.

The method in one line

Read the map. Inspect the repository. Work. Checkpoint when something material changes. Close with a reviewed update. Commit. Transfer from the repository, not from memory.
