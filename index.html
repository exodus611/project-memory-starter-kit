Does it work with ChatGPT / Claude / Cursor / …?

Yes — it adapts to the tool. In a coding agent with project access it installs and self-tests everything. In a read-only chat it hands you exact files to paste. In a plain chat it guides you step by step. It always tells you honestly which mode it's in instead of pretending.

Can I stay on the free block forever?

Of course. It covers the core loop: project memory, clean session starts, clean handoffs. The book exists for when projects get longer, riskier, or shared between several AIs — checkpoints, failure recovery, the full security protocol.

Why keep memory inside the project?

AI tools change every year — today's favorite model is tomorrow's old news. A readable, versioned project record belongs to you: inspectable, portable, and impossible to lose with a subscription.

Is my code sent anywhere?

No. There is no hosted memory service. Everything lives as plain text in your own repository, and the optional automated checks run in your own environment.
